SSH Pilot

SSH and SFTP for Linux, macOS and Windows. Free and open source.

Download↓ Source

What it does

Uses your SSH config

Reads and writes ~/.ssh/config directly. There is no import step and no second copy of your hosts to keep in sync.

Tabs and split view

An integrated terminal with tabs and splits. If you prefer your own terminal app, SSH Pilot opens sessions there instead.

Dual-pane SFTP

Move files between local and remote panes. SCP upload and download are built in.

Key transfer

Copy a public key to a server in one step, the same job ssh-copy-id does on the command line.

Docker containers

Inspect and manage the containers running on any connected host.

Secrets and backups

Store credentials in libsecret, KeePass, Bitwarden/Vaultwarden or pass. Back up and restore app settings.

Ubuntu PPA

sudo add-apt-repository ppa:mfat/sshpilot
sudo apt update
sudo apt install sshpilot

Fedora / RHEL COPR

sudo dnf copr enable mahdif62/sshpilot
sudo dnf install sshpilot
