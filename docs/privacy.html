Privacy policy

What SSH Pilot sends over the network, and how to turn it off.

SSH Pilot has no telemetry and no analytics. It never sends your connections, hosts, keys, passwords, settings or files to the SSH Pilot project or to anyone else.

Update check

When it starts, SSH Pilot asks GitHub for the latest release (api.github.com/repos/mfat/sshpilot/releases/latest). The request contains only the app's version number. GitHub sees your IP address, as with any website; GitHub's handling of it is described in the GitHub General Privacy Statement.

To turn it off, untick Check for updates on startup in the Windows installer, or turn off the same option in Preferences on any platform.

Only when you ask

These contact other servers only when you use them:

  • Connections and file transfers go to the servers you configure.
  • The Plugins page in Preferences loads the plugin list from GitHub (raw.githubusercontent.com) and downloads the plugins you turn on.
  • Importing public keys from a GitHub user fetches them from api.github.com.
  • Bitwarden setup downloads the Bitwarden command-line tool from GitHub.
  • Reporting a crash opens a new GitHub issue in your browser; nothing is sent unless you submit it there.
  • Plugins you install may contact the services you set them up for.
